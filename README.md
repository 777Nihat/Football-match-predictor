# ⚽ International Football Match Predictor

An end-to-end Machine Learning web application predicting international football match outcomes and exact scores using **LightGBM** regressors and **Poisson Distribution**.

##  Model Performance
- **1X2 Outcome Accuracy:** ~60.2%
- **Exact Score Accuracy:** ~13.1%
- **Evaluation Dataset:** 4,800+ international matches

## Tech Stack
- **Machine Learning:** LightGBM, Scikit-Learn
- **Probability Modeling:** Poisson Distribution
- **Data & Features:** Dynamic Elo Rating, Form Rolling Averages
- **Web Interface:** Streamlit
